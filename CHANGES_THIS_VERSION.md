# Changes in this version

- Environment effects were reduced to small 10-point bonuses/reductions.
- There is now only **one Environment on the board total**, not one per team.
- Playing any new Environment replaces the current Environment, even if the other team controls it.
- Environments stay active until replaced.
- Every show now has **6 Environment cards** in its 24-card pool, all at 3★.
- A legal deck must include at least **3 Environment cards from each selected show**.
- Since a deck uses 3 shows, every 48-card deck contains at least **9 Environment cards**. You can include more if you want.
- The normal rarity deck rule is unchanged: per show, select 10×3★, 5×4★, 1×5★.
- 1v1, 2v2, friendly fire, memes, and previous balance changes are preserved.
