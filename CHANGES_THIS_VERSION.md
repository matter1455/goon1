# Changes in this version

- Added room creator choice between **1v1** and **2v2**.
- 1v1 rooms start with 2 players; 2v2 rooms start with 4.
- Fixed the opening draw rule: the player taking **turn 1** after the coin flip does **not** draw; every later turn draws normally.
- Expanded every show from a forced 16-card package to a **24-card pool**:
  - 15 × 3★ available → choose 10
  - 7 × 4★ available → choose 5
  - 2 × 5★ available → choose 1
- Total catalog increased from 928 to **1,392 cards** across 58 shows.
- Added individual card selection to the deck builder. Selecting a show auto-fills a legal 10/5/1 package, then you can swap cards before readying.
- Server validates all 48 selected card IDs, not just the three show names.
- Updated the card library, rules text, README, and editing guide for the new system.
