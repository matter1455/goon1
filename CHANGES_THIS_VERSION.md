# Changes this version

- Fixed attack multipliers on AoE and split attacks.
- `next attack ×X` now applies to every target hit by that same attack instead of only the first target.
- Flat `+X next attack` bonuses now follow the same rule, so an AoE attack gets the same attack bonus against each target in that attack.
- The buff is still consumed after that one attack finishes; it does not carry into the next attack.
- Five-star immunity rules for certain next-attack multipliers are unchanged.
- Single-target attacks and punches keep their previous behavior.
